- `trilha-2.md`: briefing inicial, aproximadamente 9min38s.
- `trilha-3.md`: público, tom, conteúdo e papel das personagens, aproximadamente seis minutos.
- `trilha-4.md`: gostos, personalidade, cores e características das participantes, aproximadamente 25min11s.
